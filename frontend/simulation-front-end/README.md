# Technologie utilisée
Le frontend a été développé en React. Pour gérer l'affichage des cartes, nous utilisons le [package React Leaflet](https://react-leaflet.js.org).

# Prérequis
Afin d'exécuter le frontend, vous devez :
- installer le gestionnaire de packages `npm`
- installer les différents packages requis via la commande `npm install`

# Exécution
Pour exécuter le frontend, il suffit d'entrer la commande `npm start`.
Vous pourrez ensuite ouvrir la page [http://localhost:3000](http://localhost:3000) dans votre navigateur.
